## FAQ Chatbot

A beginner-friendly chatbot application that answers frequently asked questions (FAQs).  
This project was built as part of my internship at **Code Alpha**, using **Python (Flask)** for the backend and **HTML/CSS/JavaScript** for the frontend.

---

###  Features
- Interactive chat interface where users can type questions.
- Backend powered by Flask to process requests.
- Matches user questions with stored FAQs using string similarity (`difflib`).
- Returns the best matching answer in real time.
- Easy to expand by adding more FAQs to the dataset.

---

###  Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python, Flask  
- **Logic:** difflib (string similarity for matching questions)
